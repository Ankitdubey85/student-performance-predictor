
# Student Performance Predictor

## Project Overview
Student Performance Predictor is a Machine Learning based web application that predicts student academic performance using academic indicators.

## Features
- Predict student performance.
- Uses study hours and attendance.
- Analyzes previous examination scores.
- Considers assignment and internal marks.
- Provides academic improvement suggestions.

## Technologies Used
- Python
- Flask
- Machine Learning
- Random Forest Classifier
- Scikit-learn
- HTML
- CSS
- Pandas
- NumPy

## Input Parameters
1. Daily Study Hours
2. Attendance Percentage
3. Previous Score
4. Assignment Score
5. Internal Marks

## Performance Categories
- Excellent
- Good
- Average
- At Risk

## How to Run Locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open in browser:

```text
http://127.0.0.1:5000
```

## Dataset and Limitations
This demonstration project uses a synthetic dataset. Its predictions and evaluation results are illustrative and should not be treated as real-world student assessments.
